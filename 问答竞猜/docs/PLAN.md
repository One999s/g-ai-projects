# 重建方案与批次

## 视觉与交互
一个完整电视演播舞台，不是管理后台。深夜蓝演播大厅、透视舞台地板、金色发光答题轨道、顶部节目标识、中央聚光题板、侧边闯关阶梯和环形倒计时。四选一答案具有等待、选中锁定、正确、错误、淘汰、禁用六种状态。回答揭晓以灯光、短音效和分数上升共同反馈；不闪烁。

5题一局，连续正确附加分（100/125/150/175/200，满分750），错题或超时清空连胜。一次50:50；最终结果可复盘再开。全球知识分主题，中英可切换，新局生效。移动端按拇指操作重排，键盘1–4/A–D，减少动画和静音独立可控。

音频：用户点击后才启动WebAudio原创合成悬念音乐；页面隐藏即静音。浏览器朗读仅明确标记体验功能，不当作正式预录音频。语音输入只展示候选，用户确认才答；不默认把音频送往第三方。识别服务、隐私告知及录音权限在后续批次接入；不虚假展示已接入AI主持。

## 批次
1. 源码组织与安全骨架，最小可运行前端，持久Git提交
2. 精美可玩舞台、5题状态机、原创音效/BGM、双语与无障碍，新测试与构建
3. 服务端权威计时/计分、幂等/事务/作用域、MySQL/Redis、正式HTTP前端
4. 题包版本/审批/来源/音频审查、私有ASR候选确认、真实浏览器验收
5. 原身份协议接入、选定环境验收、备份与发布审批

每批完成测试后提交并核对远端。完成前不宣称商业发布。无钱包、支付、奖励兑现、团队或新账户平台。
