# B16 · 服务器战绩闭环

server入口与挑战结束页新增“查看我的战绩”，展示当前登录用户、当前site范围内的完成局数、最高分、累计分、累计正确题数、最长连对，以及最近最多20场完成记录。它不含其他玩家、排行榜、管理功能或个人身份字段。进行中的答题阶段不显示这个入口。

战绩来自`GET /api/quiz/me/record`。返回`{progress,recent,limit:20}`，各字段沿用已有progress/archive DTO。一个独立、5秒超时的只读REPEATABLE_READ事务完成两个SELECT，避免第五题结算恰好发生在两次读取之间时，累计数与历史行来自不同快照；事务开始与返回前均复验同一原系统身份。已有认证、Redis准入、Origin及no-store约束继续生效，无原鉴权adapter时503。DDL、六张quiz_*表与运行账号授权均不变。

历史只读quiz_scores中已唯一结算的完整五题挑战，顺序为completed_at_ms倒序、session_id正序。中途放弃、未完成或仅在浏览器演示的成绩不计入。最终第五题结算已提交、尚未按“下一步”时，服务器记录也已经有效。

前端使用单个可取消请求，严格校验字段、数值范围、历史条数、去重排序及已返回完整历史的累计一致性；异常响应显示失败状态。读取失败不伪造零分，重新读取前清空旧数据。身份失效清空战绩和结束页旧会话；关闭、离开页面、卸载或开始新挑战会取消/丢弃迟到结果。回到可见页面会重新验证并读取。记录不写入localStorage/sessionStorage，不主动轮询或调用第三方服务。

界面保留中英文本、移动端布局和键盘操作；打开后聚焦标题，Esc或收起按钮关闭并恢复触发按钮焦点。它是页面内区域，不是模态弹窗。

本轮本地验证：后端178发现=122通过+56专项跳过；实际HTTP17项包含同一JavaScript校验器从空战绩到5题750分和完成历史的读取；前端54 Node+68 DOM=122通过及双入口构建。新增真实MySQL并发合同将在本批CI验证“读累计后发生结算，当前快照仍保持旧历史，下一次读取才同时看到两者”；本地没有执行MySQL/Redis或真实身份环境，跳过不算通过。浏览器实际布局/设备验收仍未完成。
