# 收敛到可上线的必要链路

当前完成：新可玩舞台；权威规则；事务会话/结算/进度/outbox；共库连接保护；只读已审核文本题包加载。当前实际业务HTTP仍默认拒绝，演示使用本地规则，不上传成绩。

## 可以独立继续实现和验证

1. 权威会话HTTP：开局幂等、ready/current/answer/next/50:50/abandon/history/progress，调用同一事务边界；对外只返回脱敏DTO。把题包选择、幂等重放、会话创建的并发边界收紧；真实身份仍无适配器时503
2. 请求安全与Redis：认证后、正文读取前的分布式限流；正文大小/读取时间、规范路由、Origin及明确的错误契约；Redis故障默认拒绝。用一次性Redis/MySQL服务验证，不以进程内计数冒充多实例限流
3. 前端server模式：独立入口/明确状态，接真实API、服务器时间、重连、晚到响应与重复操作。以测试适配器验证HTTP全链，测试身份只留测试代码，绝不发布fake登录模式
4. 内容与音频准备：原创新题的事实来源/中英审校、有效期、许可记录；生成审核前候选包和只生成审阅SQL的导入工具。正式旁白需许可、文本/选项一致、音频hash/时长及真实试听；批准前保持draft
5. 语音答题：私有ASR代理、用户主动录音与接收方说明、按题尝试上限、资源/大小/截止限制；只给候选，显式确认后提交。点击/键盘始终可用。先确保基本HTTP游戏闭环，再接录音
6. 发布包与运维准备：精确commit构建JAR/前端产物、输入hash/测试收据、依赖/镜像审查、健康检查、备份恢复演练与小范围负载测试。当前outbox只落库，无外部消费者；独立小游戏不依赖未来游戏中心投递

## 必须有真实资料或获授权环境才能完成

- 原登录/current-user/token验证、失效/注销/撤销、账号状态、site生命周期及需要的权限/CSRF约定。实体ZIP无法替代这些实现，不能从字段猜算法
- 最终共享数据库实例、实际DDL类型/签名、已有表/history/数据版本及迁移owner批准。只确认“共用逻辑库”不等于授权原生产库迁移
- 真实身份环境的端到端回归、HTTPS/Origin/反向代理/机密注入、部署与恢复验收
- 可访问的授权浏览器预览和实际手机/麦克风/音频环境，用于视觉、交互和听感验收。当前云浏览器到驿站只见登录页，不算游戏视觉通过

钱包规则不是这个无现金竞猜MVP的依赖；团队也不在当前业务链路。AI主持、后台CMS、排行榜扩展或其他独立软件不属于当前上线关键路径。

每一批必须新测试、冻结、提交Git、核对远端及CI；不继承丢失版本测试成绩，不把源码完成或测试fixture称为生产验收。
