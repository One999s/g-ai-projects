# 独立服务器入口

`frontend/server.html` 使用同源 `/api/quiz`，不导入本地题库或计分器。构建同时生成本地演示 `index.html` 和服务器入口；任何一页都明确其模式，不自动从服务器错误回退到本地游戏。

开发模式Vite仅监听127.0.0.1，把 `/api/quiz` 代理到127.0.0.1:8081，保留Origin。生产需同源反向代理、HTTPS、原系统登录及权限契约；不要把测试身份头或虚假登录服务加入部署。身份与分布式配额未实现时503是预期保护。

## 一致性规则
- 浏览器只提交语言、资源ID、选项和幂等键；不提交分数、服务器时间或自称用户/site
- 未收到成功快照前不加分；断线答题保留同一幂等键，重试同一命令或从current同步最终结果
- 相同session只接收不落后的revision/serverNow；资源绑定错误、无效快照或格式错误拒绝显示为新结果
- 本地时钟仅估计倒计时和按钮开启；到截止时禁用答案，等待服务器判定，绝不自动判错或制造结算
- sessionStorage只保留sessionId/locale恢复提示，不存token、题库、答案、成绩或用户身份。401隐藏题面和成绩，403/404同时清除恢复提示
- 10秒请求总期限覆盖fetch和JSON响应；超时不证明服务端未执行，因此保留幂等重试
- LOADING由服务器15秒上限约束，点击准备后进入读题/答题；隐藏页面不会暂停服务器时钟
- 声音默认关，正式旁白尚未启用。B13加入可选语音候选：先核对同源服务配置与用户同意，再请求麦克风；录音发送同源服务器，由服务主机私有模型处理，不能误解成仅在用户设备推理。仍需设备与隐私部署验收

## B13 主动录音与再次确认

用户须先勾选接收方/处理位置/不持久保存说明并按下开始。服务未配置、隐私契约不匹配或窗口不足时不打开麦克风。最多6秒，到时发送识别；原游戏倒计时不停。AudioWorklet只在本机传输PCM帧，客户端转成规范16kHz mono PCM16，不使用浏览器SpeechRecognition或云语音SDK。工作模块是同源独立JS文件，不依赖data URL。

识别结果只显示文字和候选选项；需要单独确认，允许手动纠正。空/多义候选不默认选择答案。点击/键盘可在答题窗口内直接选择并取消录音。取消、撤回同意、隐藏、卸载、轮次变化、登录过期或截止会关轨道、丢弃缓冲/候选并取消在途请求；浏览器许可晚到也立即关新轨道。已经发送的请求无法被撤回，但从不自动变成答案。

开启/录音时避让本应用BGM；静音或关闭期间晚到的AudioContext resume不会重启计时器。所有音频权限均需用户交互，未在真实设备替用户申请过麦克风。

本批37 Node+51 DOM/生命周期=88测试通过；实际源码客户端的WAV编码/二进制API/候选校验器经过14项HTTP测试，合成测试识别器仅在test profile。B12真实模型记录是历史独立合成样本，不是本批浏览器或麦克风验收。没有对静态Site开放可用原系统登录/ASR的声明。

## B17 · 授权拒绝后的并发响应隔离

修复了一个可复现的客户端竞态：答题请求或语音识别返回401/403/404后，界面虽然清空，较早发出的成功轮询/答题响应仍可能再次显示旧题目与成绩；旧失败也可能覆盖随后重新验证成功的连接。

现在命令、轮询与语音拒绝共用一个失效入口。它推进游戏与语音请求代次，清空问题/分数/候选/待重试命令，停止麦克风与旁白准备，关闭战绩区域并重置忙状态。旧成功、旧失败及旧finally都不能修改新界面。旁白准备的finally也须属于当前代次，避免旧准备结束时解锁新的Ready操作。

401仅保留原有不具备认证能力的sessionId和locale提示，允许用户在原系统重新登录后向服务器重新请求current；不会用缓存题目/成绩恢复。403/404移除提示。网络超时等非授权错误仍保留原有同幂等键重试逻辑。

这不撤销服务器在拒绝前已合法提交的答案，也不假设浏览器取消等于服务端回滚。重新认证后以服务器当前状态为准。它处理“已收到授权拒绝”的边界，不能代替尚未接入的真实注销/Token撤销合同。

本轮先在B16代码上复现6条失败的交错响应测试，再修复并扩展为8条相关回归。最终前端54 Node+76 DOM=130通过，双入口构建成功。没有新增Java/DDL/身份实现，没有实际麦克风或浏览器设备验收声明。
