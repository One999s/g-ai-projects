# B24 · 完整繁体指令精确匹配

已修复 B23 实证的字形兼容缺口：原第一条固定 WAV 仍由原 small 模型转写为“我選擇第三項”，现在能给出 C 候选。候选生成不改分数/会话版本，明确确认后才从0分变成100分。原第二条仍转写为“答案13”，必须保持空候选并手动选择确认。两条固定样本的可用候选为 **1/2**，不能把一条正向和一条负向安全用例的通过写成中文识别完成。

## 具体边界

仅增加完整繁体前缀“我選擇、我選、選擇、選項、選”，及第一至第四“項/個”的明确字形。保留现有整句或明确前缀后完整表达匹配，不添加模糊拼音、数字提取、猜测、自动繁简全文转换或答案关联。原有英语、简体及选项文本精确匹配兼容。另修复旧标点归一化会抹掉问号的问题：半角、全角和Unicode兼容问号先拒绝，再做标点/空格归一化，疑问句不作为明确指令。

否定、多选、疑问语气、超范围数字和已排除项均有覆盖：“無選擇第三項”“我不選擇第三項”“我選擇第三項嗎”“我選擇第三項或第四項”“答案13”“答案十三”“第十三項”拒绝；与真实选项文字发生多个候选碰撞时仍拒绝。只读候选接口始终要求单独普通答题请求确认。
